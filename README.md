# runaround

runaround is an interactive D3.js visualization of the different meanings and
uses of the word **run**. It organizes the senses into semantic categories and
lets you explore them as a network.

## Features

- Group the meanings by word class, type of use, or detailed form.
- Search for a meaning or example.
- Select categories and individual senses to highlight related nodes.
- Drag, pan, and zoom the visualization.
- Open a detail panel for each sense.

## Project files

- `index.html` contains the page layout and interface elements.
- `style.css` contains the visual styles and responsive layout rules.
- `data.js` contains the meaning and sense data used by the visualization.
- `script.js` contains the D3.js visualization and interaction logic.

## Running the project

Open `index.html` in a browser. The page loads D3.js from its CDN, so an
internet connection is required unless that dependency is provided locally.
